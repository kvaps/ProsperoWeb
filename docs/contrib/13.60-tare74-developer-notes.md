## Confirmed changes

1. Native select popup

PlayStation WebKit and frontend popup functionality
with DualSense navigation, scrolling and selection.

2. Closed select CSS colors

Previously the native Adwaita theme painted a white
button background over the site's dark CSS background.

The PS5 build uses Adwaita rather than the inactive
RenderThemePlayStation.

RenderThemeAdwaita uses MenulistButton.

The final fix in MenuListAdwaita.cpp prevents the
native button fill from overriding the styled
MenulistButton background, preserving the CSS background
while retaining the dropdown arrow.

3. AV1 playback

The native application links FFmpeg with libdav1d.
Smooth AV1 video playback was previously reported.

## Rebuilding

Prepare the PS5 toolchain and third-party dependencies.

Extract the application source snapshot.

Prepare WebKit at the revision in BUILD_PROVENANCE.txt
and apply the project's normal WebKit patch series.

Then copy webkit-final/ files to matching paths
inside WebKit and review the changes.

Do NOT blindly apply WebKit-working-tree.diff on top
of the patch series; it is reference material.

On the original build environment:

JOBS=4 scripts/ps5/build-webkit.sh webcore

JOBS=4 bash ~/ps5_native_popup_release/build_release.sh build
